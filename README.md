# 청년층 제주 관광 동향 대시보드

청년층(20대)은 제주에서 어떤 여행을 하고 있을까? — 20대 방문 추이, 지역별 방문 특성, 검색어·온라인 후기의 관심 주제를 한 화면에서 보는 대시보드입니다.

## 화면 구성
1. 제목·분석 기간·데이터 출처
2. 필터 (기간 · 연령대 · 성별 · 시군구 · 읍면동)
3. 20대 방문 규모 / 4. 전년 동기 대비 증감률
5. 월별 방문 추이
6. 지역별 방문 (읍면동 지도 + TOP 10)
7. 인기 장소 순위
8. 관광 검색어 (워드클라우드 + 빈도 표)
9. 온라인 후기 (주요 활동 · 만족 요인 · 불편 사항)
10. 분석 결과 요약

## 데이터 출처
- 제주 관광 데이터: 월별 입도 관광객, 연령대별 방문, 읍면동별 방문객, 지역별 인기 장소, 비짓제주 검색어 순위 (2024.01~2026.08, 인기 장소는 2026.09까지). 원본 값을 바꾸지 않고 합산만 한 데이터입니다.
- 온라인 후기: 네이버 블로그 검색 결과(NAVER API HUB) 3,800건의 제목·요약문·링크 (2026-11-02 수집). 각 글의 저작권은 작성자에게 있습니다.
- 행정동 경계: [vuski/admdongkor](https://github.com/vuski/admdongkor) ver20260701 (원자료 통계청 SGIS), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- 차트: [Apache ECharts](https://echarts.apache.org/) 5.5.0, echarts-wordcloud 2.1.0

## 해석 시 유의사항
- 연령 정보는 연령대별 방문 데이터에만 있습니다. 지역·장소·검색어는 전체 관광객 기준입니다.
- 검색 수치는 관심도 지표이며 실제 방문이나 선호를 뜻하지 않습니다.
- 후기 분석은 블로그 요약문의 키워드 규칙에 따른 자동 분류이며, 작성자 연령은 확인되지 않습니다.
